Configuração Firebase

Como obter:
1. Acesse console.firebase.google.com
2. Crie um projeto → clique no ícone </> (Web App)
3. Copie os valores de apiKey e projectId
4. No menu lateral: Build → Realtime Database → Criar banco
5. Copie a URL do banco (termina em .firebaseio.com)
6. Em Regras do banco, cole:
{"rules":{".read":true,".write":true}}
